# What already exists

The task is [ABCD](https://arxiv.org/abs/2104.00783)'s Action State Tracking: predict the next agent action under a written procedure. Our numbers use dev plus dev_noisy or held-out train fold B, with conversation-bootstrap intervals ([Anthropic](https://www.anthropic.com/research/statistical-approach-to-model-evals)). IDs refer to `DECISIONS.md` and `EXPERIMENT_LOG.md`; the log's R-entries are reconstructed and unaudited unless P0-3 reproduced them.

Area | What exists | What we did and why
---|---|---
ABCD release | [kb.json](https://raw.githubusercontent.com/asappresearch/abcd/master/data/kb.json) step order, utterances.json, [snap-stanford/abcd](https://huggingface.co/datasets/snap-stanford/abcd), [GuidedTOD](https://github.com/cure-lab/GuidedTOD) code; no public ABCD intent classifier found | kb.json **not adopted**: its rule scored 71.9% vs 75.3% for a learned table (gold intent). utterances.json (~95% of dev-only long agent turns) and unlicensed snap-stanford/abcd **rejected** for leak risk. We took GuidedTOD's idea, not its code.
Next action | ABCD: masking by *predicted* intent cut cascading eval (CE) 31.3 → 30.6. [Chained Prior](https://aclanthology.org/2025.findings-naacl.377.pdf): a last-action prior lifted T5-small's CE 0.563 → 0.795. CE is multi-step, unlike our metric. | **Adopted in part:** a CPU scorer reads the last action, under a soft prior; dev action 0.812 (R4, P0-3). No GPU, so no T5.
Dialogue policy | Written plans help only on unseen workflows ([Raimondo](https://arxiv.org/abs/2306.01729)). [Zomato](https://www.together.ai/customers/zomato), [Fin](https://fin.ai/help/en/articles/13976161-manage-fin-ai-agent-s-escalation-guidance-and-rules) log escalation reasons. | **Adopted, provisional (D1):** a soft prior with the `membership` alias; violations 0.045 vs gold's 0.057 (R4). Phase 1 moves it into versioned `policy/policy.toml`, which routes off-policy picks with a logged reason; no result yet.
TF-IDF models | CLINC150: TF-IDF 80.9, zero-shot Haiku 4.5 88.5, RoBERTa 89.1 ([Rodrigues](https://arxiv.org/html/2608.20371v1)) | **Adopted:** TF-IDF, LinearSVC intent (R2), logistic-regression action; intent 0.709 (P0-3). On our data that lead vanished: Haiku intent −0.003 [−0.024, +0.018] on 1,940 dev rows, at 1.7 s vs 8 ms (P0-4, D2).
Frozen embeddings | bge-small-en-v1.5, Model2Vec potion-8M | **Not adopted.** Fused with TF-IDF (unaudited): potion −0.008 clean, −0.023 noisy intent; bge +0.007, +0.040, untested in the shipped pipeline and needing ONNX or torch.
Fine-tuned encoders | SetFit 20-shot 91.2 vs full-data MPNet 94.1 on BANKING77 ([Loukas](https://arxiv.org/html/2311.06102)) | Ettin-32M **rejected for v1.** On fold B, an equal blend with classical gained +0.0273 action but only tied Luna: +0.0026 [−0.0053, +0.0098], missing the pre-registered −0.0050 floor (`experiments/encoder/`). Cost: PyTorch (~700 MB), a 122 MB model. e5-small failed, likely our setup. SetFit **not tried:** built for few labels.
Budget LLMs | Haiku 5.5, GPT-6 Luna, Qwen3.8 27B, Gemma 4 31B, Gemini 3.5 Flash-Lite, Solar Mini 4; gpt-4.1-mini, Deployment.inc's pin; [TypeSafe Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) | **Rejected as main classifier:** best (Luna) −0.022 [−0.064, +0.017] action (R9, 360 rows). Artificial Analysis scores did not order them (Spearman −0.66 to +0.31, n = 6). **Not tested:** gpt-4.1-mini (4x Luna's input price), Jev (size undisclosed). gpt-4.1-nano, gpt-5-nano/mini **rejected**: [retiring](https://developers.openai.com/api/docs/deprecations) by 11 Dec 2026.
Routing | [RouteLLM](https://www.lmsys.org/blog/2024-07-01-routellm/) and FrugalGPT route between LLMs; our first tier is not one. [Voiceflow](https://www.voiceflow.com/stories/benchmarking-hybrid-llm-classification-systems): an encoder shortlists, an LLM picks, with 3–5x fewer input tokens on large datasets. | **Adopted:** below a confidence threshold, Luna picks from all 30 actions, shown 8 retrieved examples as [Loukas](https://arxiv.org/html/2311.06102) advises, with the CPU answer as fallback. Fold B, pre-registered: action +0.025 [+0.017, +0.032]; $0.03 per 1,000 at list with caching, $0.11 without (P0-5).
Confidence | Only the order counts ([Geifman](https://arxiv.org/abs/1705.08500)); a correctness model beat max probability ([Kamath](https://nlp.stanford.edu/pubs/kamath2020selective.pdf)); conformal sets (MAPIE, crepes) | **Adopted:** an "is the action right?" model fit on held-out train; on fold B its top-70 ratio beat p(action)'s by only 0.011 (unaudited). Top-70 ratio: 0.376 on dev (P0-3); Luna moves fold B's 0.324 → 0.380 (P0-5); bar 0.85. **Rejected:** LLM stated confidence (ratio 0.52–0.83, R9); conformal sets (sizes tie; noise may void the guarantee).
Prompt injection | [Action-Selector](https://arxiv.org/abs/2506.08837) pattern. Task-tuned base LLMs resist ([Jatmo](https://arxiv.org/abs/2312.17673): < 0.5% vs 87% attack success); linear models resisting too is our inference. | **Adopted:** Luna changes actions only on unflagged low-confidence rows, from a closed list; code sets needs_human. 3 of 9 hostile rows got confident, unrouted answers before the fix (R10); now all 9 reach a person and skip Luna (`tests/test_pipeline.py`). **Not tested:** [Prompt Guard 2](https://huggingface.co/meta-llama/Llama-Prompt-Guard-2-86M) (licence form, 512 tokens); NeMo (+3.5 s in [one report](https://github.com/NVIDIA-NeMo/Guardrails/discussions/587)); LLM Guard (heavy), Lakera (hosted), by our judgement.
Unicode, noise | [UAX #15](https://www.unicode.org/reports/tr15/): NFKC must not be applied blindly | **Adopted, own code:** drop lone surrogates, replace controls with spaces, strip zero-width and bidi, then NFKC. Zero-width "refund" now reads "refund please"; the bidi row is flagged (`tests/test_gate.py`). De-dup plus turn cap took very_long intent 0.10 → 0.68 (50 rows; P0-3: 0.68); NFKC alone did nothing (R6).
Hosted classifiers | [Zendesk triage](https://support.zendesk.com/hc/en-us/articles/4964463770650-About-intelligent-triage); [Fin](https://fin.ai/pricing), $0.99 per outcome (v1: $0.03 per 1,000 messages); [Comprehend](https://aws.amazon.com/comprehend/pricing/) | **Rejected without measuring:** none returns a next permitted action with a confidence; Fin follows admin-written Procedures but returns neither. Only the reviewer's gateway is reachable.
Serving | [uvicorn](https://uvicorn.dev/settings/) lacks body-size and timeout flags | **Adopted** FastAPI and uvicorn, plus our body cap and LLM timeout. CPU model in process, no HTTP: p95 14.6 ms (R7); with Luna about 1.8 s, offline estimate (P0-5). `scripts/loadtest.py` has yet to run with Luna.
