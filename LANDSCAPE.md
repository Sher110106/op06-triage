# What already exists

The task is [ABCD](https://arxiv.org/abs/2104.00783)'s Action State Tracking: the next agent action under a written procedure. Numbers are on dev plus dev_noisy or train fold B, with conversation-bootstrap intervals ([Anthropic](https://www.anthropic.com/research/statistical-approach-to-model-evals)); both helped choose the system. IDs refer to `DECISIONS.md` and `EXPERIMENT_LOG.md`; R-entries come from the 13 Oct probe files, archived unaudited in `results/raw/probe-2026-10-13/` (its README maps each number to a file; paths below that start `encoders/` or `llm/` are inside it); "no file" marks the one figure no file holds.

Area | What exists | What we did and why
---|---|---
ABCD release | [kb.json](https://raw.githubusercontent.com/asappresearch/abcd/master/data/kb.json) step order, utterances.json, [snap-stanford/abcd](https://huggingface.co/datasets/snap-stanford/abcd), the release's BERT-based action models, [GuidedTOD](https://github.com/cure-lab/GuidedTOD); no public ABCD intent classifier found | kb.json **not adopted**: a rule built from it scored below a table learned from train (no file). utterances.json and unlicensed snap-stanford/abcd **rejected**: leak risk. Release models **not run**: BERT fine-tuning (no GPU), multi-step metric. GuidedTOD: idea taken, not code.
Next action | ABCD: masking by *predicted* intent cut cascading eval 31.3 → 30.6. [Chained Prior](https://aclanthology.org/2025.findings-naacl.377.pdf): a last-action prior lifted T5-small 0.563 → 0.795. | **Adopted in part:** a CPU scorer reads the last action under a soft prior; dev action 0.812 (P0-3). No GPU, no T5.
Dialogue policy | Written plans help only on unseen workflows ([Raimondo](https://arxiv.org/abs/2306.01729)). [Fin](https://fin.ai/help/en/articles/13976161-manage-fin-ai-agent-s-escalation-guidance-and-rules) logs escalation reasons. [Rasa](https://rasa.com/docs/) DIET (intent) and TED (next action). | **Adopted (D1):** a soft prior with the `membership` alias (alias violations 0.044 vs gold's 0.057), the procedure in versioned `policy/policy.toml`, off-policy picks to a person. Rasa **not tried**: a TensorFlow framework that learns the policy from stories; ours is a file plus a prior.
Linear text models | CLINC150: TF-IDF 80.9, zero-shot Haiku 4.5 88.5, RoBERTa 89.1 ([Rodrigues](https://arxiv.org/html/2608.20371v1)); [fastText](https://fasttext.cc/) | **Adopted:** TF-IDF, LinearSVC intent, logistic-regression action; intent 0.709 (P0-3). On 1,940 fresh dev rows Haiku left intent accuracy flat (−0.003 [−0.024, +0.018]) but raised macro-F1 +0.031 [+0.004, +0.054] (P0-4); on fold B, LLM intent gained +0.013 to +0.014, under the 0.020 bar (P0-5). Not shipped (D2): a call per row, no action change. fastText **not tried**: another linear n-gram model.
Encoders | Frozen: bge-small-en-v1.5, Model2Vec potion-8M, multilingual-e5-small. Fine-tuned: SetFit, Ettin ([Loukas](https://arxiv.org/html/2311.06102): SetFit 20-shot near full-data MPNet) | Frozen **not adopted**: bge with TF-IDF gained +0.007 clean and +0.040 noisy intent (R8; `encoders/logs/b1_results.jsonl`) but needs ONNX or torch; potion alone scored below TF-IDF (0.670 against 0.7215 clean intent, same file); e5 failed at intent 0.348 (`ft_e5s.json`), likely a setup fault. Ettin-32M **rejected for v1** (pre-registered, E-1): on fold B an action blend 0.5/0.5 with classical (intent 0.3/0.7; weights chosen on dev) gained +0.0273 [+0.0203, +0.0341] action but tied the Luna step, +0.0026 [−0.0053, +0.0098], missing the −0.005 floor by 0.0003. Needs PyTorch (~700 MB). SetFit **not tried:** built for few labels.
Budget LLMs | Haiku 5.5, GPT-6 Luna, Qwen3.8 27B, Gemma 4 31B, Gemini 3.5 Flash-Lite, Solar Mini 4, Gemini 3.8 Flash (60 rows); fixed references gpt-5-mini, gpt-4.1-mini; [TypeSafe Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) | **Rejected as main classifier:** best (Luna) −0.022 [−0.064, +0.017] action (R9, 360 rows; `llm/report_tables.md`). **Not tested:** gpt-5-mini and gpt-4.1-mini, about $0.32 and $0.50 per 1,000 messages at the submitted run's token counts (estimate), within budget; Jev (size undisclosed); gpt-4.1-nano, gpt-5-nano ([retiring](https://developers.openai.com/api/docs/deprecations)).
Routing | [RouteLLM](https://www.lmsys.org/blog/2024-07-01-routellm/), FrugalGPT route between LLMs. [Voiceflow](https://www.voiceflow.com/stories/benchmarking-hybrid-llm-classification-systems): an encoder shortlists, an LLM picks. | **Adopted:** on low CPU confidence, Luna picks from all 30 actions, shown 8 retrieved examples. Fold B, pre-registered: +0.025 [+0.017, +0.032] action (P0-5). Submitted run: 19.9% of messages call Luna; dev action 0.812 → 0.837; $0.125 per 1,000 uncached, $0.040 cached.
Confidence | Only the order counts ([Geifman](https://arxiv.org/abs/1705.08500)); a correctness model beat max probability ([Kamath](https://nlp.stanford.edu/pubs/kamath2020selective.pdf)); conformal sets (MAPIE) | **Adopted:** an "is the action right?" model fit on held-out train. Dev top-70 ratio 0.376, against 0.419 for p(action) (P4-2), and 0.433 with Luna. **Rejected:** LLM stated confidence, which ordered errors poorly: top-70 0.52 to 0.83 (R9; `llm/llm-probe.md`). Conformal sets **not tried**: the bar scores order, not coverage.
Prompt injection | [Action-Selector](https://arxiv.org/abs/2506.08837) pattern; [Jatmo](https://arxiv.org/abs/2312.17673) | **Adopted:** Luna picks from a closed list, only on unflagged rows; code sets needs_human. All 216 actions it changed went to a person (`dev-http-llm` vs `dev-pipeline-cpu`; Luna right on 100, CPU on 43). All 9 hostile rows reach a person (R10 had 3 unrouted). **Not tested:** [Prompt Guard 2](https://huggingface.co/meta-llama/Llama-Prompt-Guard-2-86M), NeMo, LLM Guard, Lakera.
Unicode, noise | [UAX #15](https://www.unicode.org/reports/tr15/) (NFKC with care); [ftfy](https://ftfy.readthedocs.io/); [UTS #39](https://www.unicode.org/reports/tr39/) confusables | **Adopted, own code:** remove surrogates, controls, zero-width and bidi characters, then NFKC. Without de-dup, very_long intent falls 0.68 → 0.16 (P4-1; `experiments/ablations/ablations.md`). ftfy **not used**: it repairs mangled encodings, which no noise kind contains. Confusables **not handled**, untested.
Hosted classifiers | [Zendesk triage](https://support.zendesk.com/hc/en-us/articles/4964463770650-About-intelligent-triage); [Fin](https://fin.ai/pricing); [Comprehend](https://aws.amazon.com/comprehend/pricing/) | **Rejected without measuring:** none returns a next permitted action with a confidence.
Serving | [uvicorn](https://uvicorn.dev/settings/) lacks body-size and timeout flags | **Adopted** FastAPI and uvicorn with our own caps. p95 at concurrency 8: 38 ms Luna off, 1.913 s on (M1; `dev-http-cpu`, `dev-http-llm`); 151 ms off on a busy Linux box (P3-3). The first live run (`dev-http-llm-r1`) gave 1.66 s and differed on 71 of 2,300 actions: Luna's answers vary at default temperature. Every failed call in the fault runs left the CPU answer (P4-3).
